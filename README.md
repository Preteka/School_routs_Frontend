SchoolRoute - Demo Login Credentials & Quick Start

A smart school bus tracking and management web application.

🔑 Demo Login Credentials

You can use the following preset credentials to log into the application via [login.html](login.html):

 1. 👨‍💼 Administrator Account
*Access bus fleet management, driver details, student rosters, routes, and admin settings.*

- **Login URL:** `login.html` (Redirects to Admin Dashboard)
- **Email:** `admin@schoolroute.in`
- **Password:** `Admin@123`
- **Role:** Full Admin Access

 2. 👨‍👩‍👧 Parent Account
*Access real-time live bus tracking, child attendance, notifications, and subscription details.*

- **Login URL:** `login.html` (Redirects to Parent Dashboard)
- **Email:** `parent@schoolroute.in` *(or `parent@example.com`)*
- **Password:** `Parent@123`
- **Role:** Parent Access (Sample Students: Aarav & Ananya)
